Before publishing this as an openly licensed software project, the rights holder should choose and add the appropriate software licence. The technical report, project-created figures and third-party microscope material have distinct provenance. Any licence chosen for project code must explicitly preserve third-party rights and notices.

The included microscope-derived report illustrations retain the source notice in `THIRD_PARTY_NOTICES.md`. Do not assume a software licence permits unrestricted reuse of the microscopy collection or DINOv2 weights. The raw collection and pretrained weights are not bundled.
